# YouTube 时间点笔记

在 YouTube 视频中标记重要时刻、记录笔记，并随时跳回对应位置。适合语言学习、课程复习和长视频知识整理。

## 功能

- 标记视频时间点，为每个标记添加笔记。
- 使用快捷键快速标记，点击笔记跳转到对应位置。
- 用文件夹整理视频，搜索视频标题或笔记，并直接跳转到匹配的笔记。
- 导出和导入 JSON 备份，方便保存或迁移笔记。
- 支持中文和 English 界面。

## 安装

以电脑上的 Chrome 为例：

1. 打开[项目主页](https://github.com/leelianchuang-cell/youtube-bookmark-chinese-version-)，点击 **Code → Download ZIP**。
2. 解压下载的 ZIP 文件。
3. 在 Chrome 地址栏输入 `chrome://extensions/`，打开 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后包含 `manifest.json` 的文件夹。
5. 打开 YouTube 视频；如果视频页面已经打开，请刷新一次。

安装后请保留解压的文件夹。点击浏览器工具栏的扩展程序图标，可以将本扩展固定到工具栏。

## 使用

### 记录和回看

打开 YouTube 视频，在“视频笔记”面板中点击 **标记时间点**，输入笔记后点击 **保存笔记**。也可以留空文字，只保存时间点。点击笔记卡片即可跳转到对应位置。

在视频页面按 **Ctrl + Shift + Y**（Mac：**Command + Shift + Y**）也可以标记当前时间并聚焦输入框。可以在 `chrome://extensions/shortcuts` 查看或修改快捷键；如果快捷键被其他功能占用，请在那里重新设置。

### 整理和搜索

在视频页面点击 🗂 可以创建文件夹或归档视频。点击浏览器工具栏中的扩展图标，可以管理文件夹及视频记录。输入视频标题或笔记内容搜索，展开的结果中可点击时间点直接打开相应位置。

### 备份和恢复

点击扩展图标，然后选择 **导出备份**，将 JSON 文件保存在安全的位置。恢复时点击 **导入备份**，选择之前导出的 JSON 文件。

**导入会替换当前浏览器里的全部视频记录、笔记和文件夹。** 操作前建议先导出当前数据作为备份；导入前会要求确认。语言设置不会被备份覆盖。

### 切换语言

点击扩展图标，在弹窗中选择 **中文** 或 **English**。语言设置会同步应用到扩展弹窗和已打开的视频笔记面板。

## 更新已安装的扩展

先导出备份。下载并解压新版本后，在 `chrome://extensions/` 移除旧扩展并按上面的步骤加载新文件夹，再导入备份。**移除扩展可能删除原有笔记，请务必先导出并妥善保存备份。** 如果旧版本没有导出功能，请先保留原有扩展和数据，再考虑更新。

## 常见问题

**视频页面没有出现笔记面板？**  
确认扩展已启用，然后刷新 YouTube 视频页面。本扩展用于 YouTube 的普通视频观看页面。

**笔记保存在哪里？**  
笔记和文件夹保存在浏览器的本地扩展存储中，不会自动在设备间同步。卸载扩展可能删除这些数据，请定期导出备份。

**导入失败？**  
请选择本扩展导出的 JSON 备份文件。无效文件不会替换现有数据。
