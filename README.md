# YouTube 时间点笔记

一个简单实用的浏览器扩展，帮助你在观看 YouTube 视频时标记重要时刻、记录笔记，并随时回到对应位置。适合语言学习、课程复习、长视频整理和知识点记录。

## 功能

- **标记时间点**：保存视频中的精彩片段或重要内容。
- **记录笔记**：为时间点添加文字，也可以只保存时间标记。
- **快速回看**：点击笔记，跳转到视频中对应的位置。
- **分类管理**：使用文件夹整理视频和笔记，支持搜索视频标题或笔记内容。
- **编辑和删除**：随时修改笔记、删除记录或清空当前视频的笔记。

## 安装方法

以下以电脑上的 Chrome 浏览器为例：

1. 打开[项目主页](https://github.com/leelianchuang-cell/youtube-bookmark-chinese-version-)，点击绿色的 **Code** 按钮，再点击 **Download ZIP**。
2. 下载完成后解压 ZIP 文件，打开解压出来的文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions/`，按回车。
4. 打开页面右上角的 **开发者模式**。
5. 点击 **加载已解压的扩展程序**，选择刚才包含 `manifest.json` 的文件夹。
6. 安装完成后，打开一个 YouTube 视频页面。如果之前已经打开了视频，请刷新页面。

> 安装后请保留解压的文件夹，不要随意移动或删除它。也可以点击浏览器工具栏的“扩展程序”图标，将此扩展固定到工具栏，方便打开。

## 使用方法

### 记录和回看

1. 打开 YouTube 视频，找到页面上的 **视频笔记**面板。
2. 播放到想记录的位置时，点击 **标记时间点**。
3. 在输入框中填写笔记，然后点击 **保存笔记**。也可以不填文字，只保存时间点。
4. 想要回看时，点击笔记卡片，视频就会跳转到对应位置。

不手动标记时间点时，点击保存会使用保存时的视频播放位置。笔记旁的按钮可以编辑或删除该条记录；面板右上角的按钮可以收起面板，点击 📝 图标可重新展开。

### 整理和查找

- 在视频笔记面板中点击 🗂，可以新建文件夹或将当前视频归档。
- 点击浏览器工具栏中的扩展图标，可以查看视频列表和笔记、创建文件夹、移动视频，以及按视频标题或笔记内容搜索。
- 在扩展弹窗中展开视频记录后，点击笔记的时间点，可以打开视频并跳转到对应位置。

## 常见问题

**安装时提示找不到弹出页面？**  
请确认下载并完整解压了最新版本，并选择包含 `manifest.json` 的文件夹。

**打开视频后没有看到笔记面板？**  
请确认扩展已启用，然后刷新 YouTube 视频页面。本扩展用于 YouTube 的普通视频观看页面。

**笔记保存在哪里？**  
笔记和文件夹保存在浏览器的本地扩展存储中，不会自动在不同设备之间同步。卸载扩展可能会删除这些数据，请谨慎操作。
